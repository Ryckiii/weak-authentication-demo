Two things to know +

MFA needs different factor types: something you know, have, or are. A password + a PIN is still only “something you know.” MFA helps, but does not stop every attack.

Rate limiting slows guesses. A short wait or temporary lockout can help. Long lockouts may also block the real user. Use more than one defense.

Q&A · 06:30–08:00
Why is a complex reused password still risky?+

If one site leaks your password, an attacker can try it on other sites. A hard-to-guess password still works if someone already knows it. Use a different password for every account.

Does a password plus a PIN count as MFA?+

No. Both are things you know. MFA needs different factor types, such as a password and a code from a device you have. Two steps do not always mean two factors.

If we have MFA, why do we still need other defenses?+

Each defense helps with a different problem. MFA adds a check, rate limiting slows guesses, and unique passwords stop one leaked password from working everywhere.
